<p align="center">
  A dedicated Next.js financial workstation built around Bitcoin satoshis (1 BTC = 100M Sats). Features real-time fee-rate estimations (mem-pool telemetry), fiat valuation in Sats, and lightning network fee calculators.
</p>

## ⚡ Features
- 🪙 **Sats-Standard Valuation**: View fiat purchasing power denominated in Satoshis rather than fractional BTC.
- ⛽ **Mempool & Fee Telemetry**: Real-time high, medium, and low priority sat/vB recommendations.
- ⚡ **Lightning Invoice Breakdown**: Parse and analyze Lightning Network bolt11 payment invoices.

## 🇮🇷 توضیحات فارسی (Persian Description)
### معرفی داشبورد بیت‌کوین و ساتوشی PIMXSATS
پروژه **PIMXSATS** یک پلتفرم نسل جدید بر پایه **Next.js 15** است که برای رصد قیمت بیت‌کوین بر مبنای واحد ساتوشی (Sats)، بررسی لحظه‌ای کارمزدهای شبکه مم‌پول (Mempool) و ابزارهای محاسباتی شبکه لایتنینگ طراحی شده است.
